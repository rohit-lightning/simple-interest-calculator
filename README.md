
# Simple Interest Calculator

A simple Python project to calculate simple interest
using principal amount, rate of interest, and time.

## Project Description

This project calculates simple interest based
on the values entered by the user.

## Formula

Simple Interest = (Principal * Rate * Time) / 100

## Technologies Used

- Python 3

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Run:

python simple_interest.py

## Example

Principal Amount: 67
Rate of Interest: 89
Time: 9 years

Output:

Simple Interest: 536.67
